# Session 02 - JS Fundamentals

## 1. المتغيرات (Variables)
- **`const`**: الأساسي والافتراضي، قيمته لا تتغير بعد تعريفه (No Reassign).
- **`let`**: بنستخدمه فقط لو القيمة هتتغير قدام (زي عداد اللوب أو عمليات الحساب).
- **`var`**: طريقة قديمة ومفيش سبب لاستخدامها نهائياً لتجنب مشاكل الـ Scope والـ Hoisting.

<div dir="ltr">

```javascript
const course = "JavaScript Everywhere";
let session = 1;
session = 2; // مسموح مع let
```

</div>

## 2. ليه بنقدر نعدل على `Object` و `Array` مع إنهم `const`؟
- في المتغيرات البدائية (Primitives زي الأرقام والنصوص)، `const` بتمنع تغيير القيمة نفسها.
- لكن مع **`Object`** و **`Array`**، المتغير مش بيشيل البيانات جواه مباشرة، هو بيشيل **عنوانهم في الذاكرة (Reference)**.
- كلمة `const` بتمنعك من **تغيير العنوان** (يعني ممنوع تساويه بـ Object أو Array جديد)، لكن مسموح تعدل وتضيف وتمسح محتويات نفس الصندوق عادي لأن العنوان ثابت في الذاكرة.

<div dir="ltr">

```javascript
const student = { name: "Ahmed", city: "Qena" };
student.city = "Cairo"; // مسموح

const tracks = ["Web"];
tracks.push("Mobile"); // مسموح

// student = { name: "Ali" }; // خطأ ممنوع لأنك بتغير العنوان
```

</div>

## 3. أنواع البيانات (Data Types)
- **الأنواع البدائية (7 Primitives)**:
  - `string`: نصوص.
  - `number`: أرقام صحيحة وعشرية معاً.
  - `boolean`: صح أو خطأ (`true` / `false`).
  - `null`: قيمة فارغة عمداً (المبرمج هو اللي محدد إنها فارغة).
  - `undefined`: متغير تم تعريفه لكن لم يأخذ قيمة بعد.
  - `bigint`: للأرقام الضخمة جداً.
  - `symbol`: معرّف فريد ونادر الاستخدام.
- **الكائنات (Objects)**: تشمل الـ Objects والـ Arrays والدوال (`typeof []` و `typeof {}` بيعطوا `"object"`).
- **فحص المصفوفة**: للتأكد من أن المتغير Array، استخدم `Array.isArray(arr)` لأن `typeof` هترجع لك `"object"`.
- **خطأ تاريخي**: `typeof null` بترجع `"object"`، وده Bug قديم في جافاسكريبت من سنة 1995 وما زال موجوداً حتى لا تتعطل المواقع القديمة.

## 4. التحويل بين الأنواع (Type Casting & Coercion)
جافاسكريبت تقوم بتحويل الأنواع تلقائياً (Coercion) وده بيسبب أخطاء غير متوقعة:

<div dir="ltr">

```javascript
"5" + 3; // "53" (علامة + مع النصوص بتدمج النصوص)
"5" - 3; // 2    (علامة - بتحول النص لرقم تلقائياً)
```

</div>

الأفضل دائماً التحويل الصريح بنفسك (Explicit Conversion):

<div dir="ltr">

```javascript
Number("42");     // 42
String(42);       // "42"
Boolean(1);       // true
parseInt("42px"); // 42
```

</div>

## 5. قيم الـ Truthy والـ Falsy
في جافاسكريبت، أي قيمة بتتحول لـ `true` أو `false` داخل الشروط.  
هناك **8 قيم فقط تعتبر Falsy دائماً**، وأي قيمة أخرى في اللغة تعتبر Truthy:

```text
false, 0, -0, 0n, "", null, undefined, NaN
```

- **تنبيه مهم**: المصفوفة الفارغة `[]` والكائن الفارغ `{}` يعتبران **Truthy** حتى لو كانوا فاضيين!  
  للتأكد من أن المصفوفة فارغة، افحص طولها: `arr.length === 0`.

## 6. المعاملات (Operators)

### الفرق بين `===` و `==`:
- **`===` (Strict)**: تقارن **القيمة والنوع معاً**، وهي اللي بنستخدمها دائماً.
- **`==` (Loose)**: تقارن القيمة فقط وتعمل تحويل أنواع من وراك، وده بيسبب أخطاء (مثلاً: `"5" == 5` نتيجتها `true`).

### المعاملات المنطقية:
- **`&&` (AND)**: لازم الطرفين يكونوا `true`.
- **`||` (OR)**: يكفي طرف واحد يكون `true`، وتبحث عن أول قيمة Truthy.

### المعاملات الحديثة (`??` و `?.`):
- **معامل `??` (Nullish Coalescing)**:  
  بديل ممتاز لـ `||` لإعطاء قيمة افتراضية، لأنه يتجاهل فقط `null` و `undefined`.  
  لو القيمة كانت `0`، بيعتبرها قيمة صالحة ومبيغيرهاش:

<div dir="ltr">

```javascript
let score = 0;
console.log(score || 100); // 100 (خطأ لأن 0 سقط كقيمة Falsy)
console.log(score ?? 100); // 0   (صح لأن 0 مش null ولا undefined)
```

</div>

- **معامل `?.` (Optional Chaining)**:  
  وظيفته يمنع انهيار البرنامج (Crash) لو بتحاول تقرأ خاصية من كائن غير موجود (`null` أو `undefined`).  
  لو الخاصية مش موجودة، بيرجع `undefined` بأمان تام بدون ما يطلع Error في الكود:

<div dir="ltr">

```javascript
const user = { name: "Ahmed" };

// بدون ?. الكود هيضرب كراش ويوقف البرنامج:
// console.log(user.address.city); // TypeError

// مع ?. هيرجع undefined بأمان:
console.log(user.address?.city); // undefined
```

</div>

## 7. الجمل الشرطية (Conditionals)

- **`if / else if / else`**: رتّب الشروط دائماً من الأضيق فالأوسع.
- **المعامل الثلاثي (Ternary Operator `? :`)**: اختصار لجمل `if / else` البسيطة:

<div dir="ltr">

```javascript
const result = score >= 70 ? "PASS" : "FAIL";
```

</div>

- **جملة `switch`**: لمقارنة متغير واحد بقيم محددة وثابتة (بتقارن بـ `===`). لازم تضع `break` بعد كل `case` حتى لا ينتقل لتنفيذ الحالات التالية (Fall-through).

## 8. حلقات التكرار (Loops)

- **`for...of`**: أفضل وأحدث طريقة للمصفوفات (بتمر على القيم مباشرة):

<div dir="ltr">

```javascript
for (const track of tracks) {
  console.log(track);
}
```

</div>

- **`for` التقليدية**: بنستخدمها لما نكون محتاجين رقم الـ index:

<div dir="ltr">

```javascript
for (let i = 0; i < tracks.length; i++) {
  console.log(i, tracks[i]);
}
```

</div>

- **`for...in`**: للكائنات (Objects) فقط لأنها بتلف على الـ Keys. تجنب استخدامها مع المصفوفات.
- **`while`**: لما تكون مش عارف عدد مرات التكرار مسبقاً، والتكرار مستمر طالما الشرط متحقق.
- **`do...while`**: تشبه `while` لكن بتضمن إن الكود يتنفذ مرة واحدة على الأقل.
- **`forEach`**: دالة جاهزة في المصفوفات، عيبها الوحيد إنها لا تدعم إيقاف اللوب بـ `break`.

### الفرق بين `break` و `continue`:
- **`continue`**: تتخطى الدورة الحالية فقط وتكمل باقي الدورات.
- **`break`**: توقف حلقة التكرار بالكامل وتخرج منها فوراً.
