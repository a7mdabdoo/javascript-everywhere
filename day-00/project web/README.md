# TaskFlow

A lightweight Kanban-style task management board built with HTML5, CSS3, and Vanilla JavaScript.

## Features
- **3-Stage Workflow:** Organize tasks across **TO DO**, **IN PROGRESS**, and **DONE** columns.
- **Dynamic Movement:** Move cards left and right across columns based on their current status.
- **Live Counters:** Real-time task count displayed in each column header.
- **Theme Switcher:** Dark Mode and Light Mode toggle using CSS custom properties.
- **Keyboard Shortcut:** Quickly add tasks by pressing the `Enter` key.
- **Task Deletion:** Remove completed or unwanted tasks.

## Tech Stack
- **HTML5:** Semantic page layout and structure.
- **CSS3:** Flexbox layout, responsive design, custom color variables, and transition effects.
- **Vanilla JavaScript:** DOM manipulation, event handling, and local state management.

## Project Structure
```text
project web/
├── index.html   # Main application markup and layout
├── style.css    # Styling, layout, and theme color variables
├── script.js    # State management and DOM interaction logic
└── README.md    # Project overview and documentation
```

## How to Run
1. Clone or download this repository.
2. Open `index.html` in any modern web browser, or launch it with the VS Code **Live Server** extension.
